# 原型设计

- 项目：**Rover X1 智能巡检管控平台**
- 设计系统：**CyberHound Operations Cockpit**
  - 深色赛博指挥舱风格：底色 `#0b1326`，主色科技青 `#00f2fe`，辅助翠绿 `#10b981`，警示红 `#f43f5e`
  - 字体：标题 Space Grotesk / 正文 Inter / 数据 JetBrains Mono
  - 组件语言：磨砂玻璃面板、四角机械切角、发光描边、状态信号灯塔

## 页面清单（桌面端 2560px）

| # | 页面 | 内容 |
| --- | --- | --- |
| 01 | 总览驾驶舱 | 三栏大屏：设备统计与告警分布环图 / 2.5D 园区数字孪生地图（机器狗位置、巡检路线、实时告警流）/ 机器狗集群状态与 7 天趋势 |
| 02 | 实时监控中心 | 多路视频通道列表、主画面（十字线/坐标/FPS/REC 叠加）、四宫格视频墙、远程操控面板（摇杆、姿态切换、语音喊话、紧急制动/人工接管） |
| 03 | 巡检任务管理 | 任务列表（状态筛选、进度条）、路线编辑地图（可拖拽点位）、任务配置表单（定时/周期、AI 检测项勾选、保存并下发） |
| 04 | 告警中心 | 告警统计条、级别/类型筛选、告警列表、详情面板（AI 检测框抓图、置信度、处置时间线、确认/误报/派单闭环） |
| 05 | 设备管理 | 机器狗集群卡片（电量/里程/信号）、单机详情（3D 视图、健康度、传感器与通信链路状态、OTA 升级/标定/重启运维操作） |
| 06 | 巡检报告 | 多维筛选与导出、趋势/分布/热力图表、巡检记录归档表格（可追溯、闭环率统计） |


## 前端落地对应

`web/` 前端按以上 6 个页面实现，设计 token（颜色/字体/圆角/间距）以设计系统 `designMd` 为准。
