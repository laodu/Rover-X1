# ai — AI 巡检算法

对机器狗回传视频流做实时分析，输出结构化告警（类型、置信度、位置、抓图、短视频）。

## 首期检测项

烟火识别、人员越界、垃圾满溢、表计读数、红外过温（需热成像上装）、气体异常（CO/H₂S，需气体传感器）、道路占用与积水。

## 目录

- `inference/` — 推理服务：拉流 → 抽帧 → 多模型检测 → 告警事件推送 server
- `pipelines/` — 各检测项流水线与后处理规则（去抖、区域过滤、阈值）
- `training/` — 数据标注与训练脚本（YOLO 系）
- `models/` — 模型权重与版本管理（ONNX/TensorRT）
