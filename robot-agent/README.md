# robot-agent — 机器狗端代理

运行于机器狗上位机（Ubuntu 22.04），基于 [dobot_quad_sdk](https://github.com/Dobot-Team/dobot_quad_sdk) 桥接机器人与云端平台。

## 职责

- 通过高层 gRPC 执行云端下发的巡检任务与遥控指令（状态机、运动规划、速度控制）
- 通过低层 DDS 采集 RGB-D 相机、IMU、电机、电池等遥测数据（有线接入时）
- 拉取相机 RTSP 视频流并推流至云端流媒体网关
- 心跳与状态上报（MQTT），断网本地缓存、恢复后补传
- 接收 OTA 升级包并执行升级

## 目录

- `app/` — 代理主程序（任务执行器、采集器、推流器、指令通道）
- `configs/` — 机器人 IP（有线 192.168.5.2 / WiFi 192.168.1.6）、MQTT 与推流地址、采集频率
